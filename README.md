**Smoking & Healthcare Risk Analysis** (Power BI)

Welcome to the Smoking & Healthcare Risk Analysis project 🚭📊.
This repository showcases an end-to-end Power BI healthcare analytics project focused on understanding smoking behavior and its impact on key health risk factors. The project is designed as a portfolio project and emphasizes clean data modeling, meaningful insights, and clear visual storytelling.


---

📌 ***Project Overview***

This project involves:

1. Healthcare Data Analysis – Exploring patient data with a focus on smoking status and associated health risks.


2. Data Preparation & Modeling – Cleaning, transforming, and modeling data to support analysis.


3. Dashboard Development – Building interactive Power BI dashboards for clear and actionable insights.


4. Analytics & Storytelling – Presenting insights in a simple, accurate, and easy-to-understand way.




---

🎯 **Objective**

The main objective of this project is to:

Analyze smoking patterns across patients

Identify health risks linked to smoking behavior

Present insights through interactive Power BI visuals

Practice healthcare-focused data analytics with an emphasis on accuracy and clarity



---

📊 **Key Insights Covered**

Smoking status distribution (Never, Current, Former)

Health risk indicators related to smoking

Demographic-based analysis (e.g., gender, age groups)

Comparative health outcomes between smokers and non-smokers



---

🧱 **Data Architecture**

This project follows a simple analytics workflow:

Data Source → Data Cleaning → Data Modeling → Power BI Dashboard

Raw data is prepared and cleaned before analysis

Data is modeled to support efficient reporting

Final insights are delivered using Power BI dashboards



---

🛠️ **Tools & Technologies Used**

Power BI Desktop – Dashboard development & visualization

DAX – Measures and calculated columns

Data Modeling – Relationships and schema design

Excel / CSV – Data source format

GitHub – Version control and project documentation
